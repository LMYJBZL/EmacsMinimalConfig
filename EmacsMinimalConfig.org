本 Org 是 Emacs 配置源文件。LaTeX 部分使用 AUCTeX 的编辑、编译和预览功能，
论文、课件及其他 TeX 文档使用相同设置。

- =C-c C-c=：调用 LaTeXMk 编译，默认使用 XeLaTeX；文件或目录局部变量可指定其他引擎。
- =M-q=：使用 AUCTeX 原生段落整理；普通保存不自动重排正文。
- =C-c C-v=：通过 Skim 预览工作 PDF，并使用 SyncTeX 双向定位。

共享模板、图片和参考文献按下方的 TeX 资源路径加载。
编译辅助文件保留在 =.LaTeXOut/=，最终 PDF 复制到主文件旁。
公共解析信息保留在 =TeX/el/=，手写样式放在 =TeX/el/manual/=；
公共模板保存后可用原生 =M-x TeX-auto-generate= 刷新解析信息。

日常修改后使用 =C-c C-v t= 导出配置及 Snippets，再重新启动 Emacs。
若要删除整个 =~/.emacs.d/=，先退出 Emacs，再按 [[file:README.org::*完整重建][完整重建说明]]
使用不加载个人配置的独立进程 tangle；目标目录不存在时会自动创建。
Snippets 的源文件也保存在本 Org 中，导出到 =~/.emacs.d/etc/snippets/=，与配置一起管理版本。
本仓库只跟踪 =EmacsMinimalConfig.org=；说明、测试及其他本地文件通过
=.git/info/exclude= 忽略。该忽略规则保存在当前仓库，换电脑重新克隆时需重新设置。
所需扩展包由配置安装，首次安装需要网络。MacTeX、Skim、字体和 Notes 资源
属于独立资源；删除 =~/.emacs.d/= 前仍应保存个人缩写、
=etc/custom.el=、=etc/abbrev_defs= 和需要保留的 =var/= 历史数据及恢复文件。

** macOS Native Compilation Target

启动时向原生编译器提供 macOS 的实际版本，避免旧版 libgccjit 将新版系统误判为 =18.0=。
保留环境中已明确指定的 =MACOSX_DEPLOYMENT_TARGET=；原生编译仍然启用。

#+begin_src emacs-lisp
(defun my/macos-native-compilation-setup ()
  "Supply macOS's product version when no explicit compiler target is set."
  (when (and (eq system-type 'darwin)
             (featurep 'native-compile)
             (not (getenv "MACOSX_DEPLOYMENT_TARGET"))
             (file-executable-p "/usr/bin/sw_vers"))
    (let ((product-version
           (with-temp-buffer
             (when (eq (call-process "/usr/bin/sw_vers" nil t nil "-productVersion") 0)
               (string-trim (buffer-string))))))
      (when (and product-version
                 (string-match-p "\\`[0-9]+\\(?:\\.[0-9]+\\)*\\'" product-version))
        (setenv "MACOSX_DEPLOYMENT_TARGET" product-version)))))

;; Set this before loading custom.el or advising native functions.
(my/macos-native-compilation-setup)
#+end_src

** Garbage Collection

启动期间使用 128 MiB 分配阈值和 0.6 的堆比例，避免首次安装时无限推迟回收；
启动完成后恢复到 32 MiB 和 0.1。
这里已负责恢复正常阈值，不再叠加另一套 GC 管理包。

#+begin_src emacs-lisp
;; Garbage collection significantly affects startup times. This setting delays
;; garbage collection during startup but will be reset later.

(defun minimal-emacs--restore-gc-values ()
  "Restore garbage collection values to minimal-emacs.d values."
  (setq gc-cons-threshold minimal-emacs-gc-cons-threshold)
  (setq gc-cons-percentage minimal-emacs-gc-cons-percentage))

(defun minimal-emacs--restore-gc ()
  "Restore garbage collection settings."
  (if (and (bound-and-true-p minimal-emacs-gc-cons-threshold-restore-delay)
           ;; In noninteractive mode, the event loop does not run
           (not noninteractive))
      ;; Defer garbage collection during initialization to avoid 2 collections.
      (run-with-timer minimal-emacs-gc-cons-threshold-restore-delay nil
                      #'minimal-emacs--restore-gc-values)
    (minimal-emacs--restore-gc-values)))

(when minimal-emacs-optimize-startup-gc
  (add-hook 'emacs-startup-hook #'minimal-emacs--restore-gc 105))
#+end_src

*** File-Name-Handler-Alist

#+begin_src emacs-lisp
(defvar minimal-emacs--old-file-name-handler-alist (default-toplevel-value
                                                    'file-name-handler-alist))

(defun minimal-emacs--respect-file-handlers (fn args-left)
  "Respect file handlers.
FN is the function and ARGS-LEFT is the same argument as `command-line-1'.
Emacs processes command-line files very early in startup. These files may
include special paths like TRAMP paths, so restore `file-name-handler-alist' for
this stage of initialization."
  (let ((file-name-handler-alist (if args-left
                                     minimal-emacs--old-file-name-handler-alist
                                   file-name-handler-alist)))
    (funcall fn args-left)))

(defun minimal-emacs--restore-file-name-handler-alist ()
  "Restore `file-name-handler-alist'."
  (set-default-toplevel-value
   'file-name-handler-alist
   ;; Merge instead of overwrite to preserve any changes made since startup.
   (delete-dups (append file-name-handler-alist
                        minimal-emacs--old-file-name-handler-alist))))

(when (and minimal-emacs-optimize-file-name-handler-alist
           (not minimal-emacs-debug))
  ;; Determine the state of bundled libraries using calc-loaddefs.el. If
  ;; compressed, retain the gzip handler in `file-name-handler-alist`. If
  ;; compiled or neither, omit the gzip handler during startup for improved
  ;; startup and package load time.
  (set-default-toplevel-value
   'file-name-handler-alist
   (if (locate-file-internal "calc-loaddefs.el" load-path)
       nil
     (list (rassq 'jka-compr-handler
                  minimal-emacs--old-file-name-handler-alist))))

  ;; Ensure the new value persists through any current let-binding.
  (put 'file-name-handler-alist 'initial-value
       minimal-emacs--old-file-name-handler-alist)

  ;; Emacs processes command-line files very early in startup. These files may
  ;; include special paths TRAMP. Restore `file-name-handler-alist'.
  (advice-add 'command-line-1 :around #'minimal-emacs--respect-file-handlers)

  (add-hook 'emacs-startup-hook #'minimal-emacs--restore-file-name-handler-alist
            101))
#+end_src

(defun my/hidden-file-p (file)
  "Return non-nil for dotfiles or documents normally hidden when browsing."
  (let ((name (file-name-nondirectory (directory-file-name file)))
        (case-fold-search t))
    (or (string-prefix-p "." name)
        (and (not (directory-name-p file))
             (string-match-p my/hidden-document-regexp name)))))

      (not (stringp file))

      ;; hidden filename also keeps it available for ordinary RET selection.

                 (string-prefix-p "." name))
            (equal (downcase typed) (downcase name))))))

*** Orderless

普通候选用空格分词，词序不限；命令、变量和符号额外支持首字母匹配。

#+begin_src emacs-lisp
(use-package orderless
  :if (or (not noninteractive) (locate-library "orderless"))
  :demand t
  :config

  (defun +orderless--consult-suffix ()
    "Regexp which matches the end of string with Consult tofu support."
    (if (boundp 'consult--tofu-regexp)
        (concat consult--tofu-regexp "*\\'")
      "\\'"))

  ;; Recognizes the following patterns:
  ;; * .ext (file extension)
  ;; * regexp$ (regexp matching at end)
  (defun +orderless-consult-dispatch (word _index _total)
    (cond
     ;; Ensure that $ works with Consult commands, which add disambiguation suffixes
     ((string-suffix-p "$" word)

**** Tab 与 Del

=Tab= 优先展开 Yasnippet，或跳到片段的下一个输入点；片段结束后，
在当前数学环境内逐层进入、退出括号，最后停在公式结束处。
正文、选区和数学行首使用原生缩进；=C-u Tab= 始终直接缩进。
Tab 不触发普通命令补全，数学公式退出后反复按 Tab 保持原位。

普通补全使用 AUCTeX 原生命令，在迷你缓冲区通过 Vertico 选择：

- =C-c C-m=（也可 =C-c RET=）：插入宏，按需要询问参数。
- =C-c C-e=：AUCTeX 原生环境插入。

=C-c C-f= 保留 AUCTeX 原生字体按键，随后按一个键选择字体命令。

编辑区不自动弹出候选；Tab 不调用 =completion-at-point=。
=Del= 删除整个括号符号；括号内只有空白时删除整对，有内容时保留内容。
注释和 verbatim 中保留普通删除；不同大小命令包围的空括号也可整对删除。

(require 'cl-lib)

(defconst my/latex-basic-delimiter-pairs
  '(("(" . ")") ("[" . "]") ("{" . "}")
    ("\\{" . "\\}") ("|" . "|") ("\\|" . "\\|")
    ("\\lfloor" . "\\rfloor") ("\\lceil" . "\\rceil")
    ("\\langle" . "\\rangle") ("\\backslash" . "\\backslash"))
  "Delimiter shapes, independent of their sizing commands.")

(defconst my/latex-delimiter-pairs
  (let ((basic my/latex-basic-delimiter-pairs))
    (append basic '(("\\(" . "\\)") ("\\[" . "\\]") ("\\left." . "\\right."))
            (cl-loop for (left . right) in basic
                     unless (equal left "{")
                     append
                     (append
                      (cl-loop for (open . close) in
                               '(("\\left" . "\\right") ("\\bigl" . "\\bigr")
                                 ("\\Bigl" . "\\Bigr") ("\\biggl" . "\\biggr")
                                 ("\\Biggl" . "\\Biggr"))
                               collect (cons (concat open left) (concat close right)))
                      (list (cons (concat "\\left" left) "\\right.")
                            (cons "\\left." (concat "\\right" right)))))))
  "Recognized delimiter pairs, shared by TAB and DEL.")

(defconst my/latex-delimiter-regexp
  (regexp-opt (delete-dups (append (mapcar #'car my/latex-delimiter-pairs)
                                   (mapcar #'cdr my/latex-delimiter-pairs))))
  "Regexp recognizing whole LaTeX delimiters.")

(defun my/latex-delimiters-match-p (left right)
  "Match delimiter shapes even when LEFT and RIGHT use different sizes."
  (or (member (cons left right) my/latex-delimiter-pairs)
      (let ((prefix "\\`\\\\\\(?:left\\|right\\|[Bb]igg?[lr]\\)"))
        (member (cons (replace-regexp-in-string prefix "" left)
                      (replace-regexp-in-string prefix "" right))
                my/latex-basic-delimiter-pairs))))

(defun my/latex-delimiter-before ()
  "Return (START . TOKEN) for the longest delimiter immediately before point."
  (save-match-data
    (let* ((start (max (point-min) (- (point) 30)))
           (text (buffer-substring-no-properties start (point))))
      (when (string-match (concat my/latex-delimiter-regexp "\\'") text)
        (let ((beg (+ start (match-beginning 0)))
              (token (match-string 0 text)))
          (unless (or (TeX-escaped-p beg)
                      (and (string-match-p "[[:alpha:]]\\'" token)
                           (string-match-p "[A-Za-z@]" (char-to-string (or (char-after) ?\ )))))
            (cons beg token)))))))

(defun my/latex-backspace (arg)
  "Delete a whole delimiter, or both sides when the pair is empty.
An active region or prefix argument keeps ordinary deletion behavior."
  (interactive "p")
  (let ((end (point)))
    (cond
     ((use-region-p) (delete-region (region-beginning) (region-end)))
     ((or (/= arg 1) (nth 4 (syntax-ppss)) (TeX-verbatim-p))
      (backward-delete-char-untabify arg))
     (t
      (if-let* ((symbol (my/latex-delimiter-before)))
          (let* ((beg (car symbol))
                 (token (cdr symbol))
                 (empty-pair
                  (save-excursion
                    (or
                     ;; Empty pair after its opening delimiter.
                     (progn
                       (skip-chars-forward " \t\n\r")
                       (and (looking-at my/latex-delimiter-regexp)
                            (not (and (eq (char-syntax (char-before (match-end 0))) ?w)
                                      (string-match-p "[A-Za-z@]"
                                                      (char-to-string (or (char-after (match-end 0)) ?\ )))))
                            (my/latex-delimiters-match-p token (match-string-no-properties 0))
                            (cons beg (match-end 0))))
                     ;; Empty pair after its closing delimiter.
                     (progn
                       (goto-char beg)
                       (skip-chars-backward " \t\n\r")
                       (when-let* ((left (my/latex-delimiter-before)))
                         (and (my/latex-delimiters-match-p (cdr left) token)
                              (cons (car left) end))))))))

                           (if empty-pair (cdr empty-pair) end)))

(defun my/latex-math-end ()
  "Return (CLOSING-START . AFTER-CLOSING) for the enclosing math.
Text arguments inside math remain part of delimiter navigation."
  (save-excursion
    (save-match-data
      (condition-case nil
          (let ((math (texmathp)))
            ;; AUCTeX correctly treats \\text arguments as text.  For TAB
            ;; navigation, look before those macros for their enclosing math.
            (while (and (not math)
                        (eq (cadr (assoc (car texmathp-why)
                                         texmathp-tex-commands1)) 'arg-off)
                        (integer-or-marker-p (cdr texmathp-why))
                        (< (cdr texmathp-why) (point)))
              (goto-char (cdr texmathp-why))
              (setq math (texmathp)))
            (when math
              (let* ((name (car texmathp-why))
                     (start (cdr texmathp-why))
                     (closing (cdr (assoc name '(("$" . "$") ("$$" . "$$")
                                                 ("\\(" . "\\)") ("\\[" . "\\]"))))))
                (goto-char start)
                (cond
                 (closing
                  (forward-char (length name))
                  (catch 'found
                    (while (TeX-search-forward-unescaped closing nil t)
                      (let ((beg (match-beginning 0)) (end (point)))
                        (unless (or (TeX-verbatim-p beg)
                                    (save-excursion (nth 4 (syntax-ppss beg))))
                          (throw 'found (cons beg end)))))))
                 ((looking-at "\\\\begin[ \t]*{[^}\n]+}")
                  (goto-char (match-end 0))
                  (LaTeX-find-matching-end)
                  (let ((end (point)))
                    (search-backward "\\end" start)
                    (cons (point) end)))
                 ((eq (cadr (assoc name texmathp-tex-commands1)) 'arg-on)
                  (when (re-search-forward "{" nil t)
                    (let ((end (scan-sexps (1- (point)) 1)))
                      (and end (cons (1- end) end)))))))))
        (error nil)))))

(defun my/latex-math-forward ()
  "Advance through delimiters, then stop just after the current math."
  (when-let* ((bounds (my/latex-math-end))
              ((<= (point) (car bounds))))
    (let ((argument (eq (cadr (assoc (car texmathp-why)
                                     texmathp-tex-commands1)) 'arg-on)))
      (let ((target
             (save-excursion
               (catch 'found
                 (while (re-search-forward
                         (concat (regexp-quote "\\")
                                 "\\(?:begin\\|end\\)[ \t]*{[^}\n]+}\\|"
                                 my/latex-delimiter-regexp)
                         (car bounds) t)
                   (let ((beg (match-beginning 0))
                         (end (match-end 0)))
                     (unless (or (TeX-escaped-p beg)
                                 (and (eq (char-syntax (char-before end)) ?w)
                                      (string-match-p "[A-Za-z@]"
                                                      (char-to-string (or (char-after end) ?\ ))))
                                 (TeX-verbatim-p beg)
                                 (save-excursion (nth 4 (syntax-ppss beg))))
                       (goto-char end)
                       ;; Adjacent arguments, e.g. \frac{a}{b}, take one TAB.
                       (when (memq (char-before end) '(?\) ?\] ?\}))
                         (let ((next (save-excursion
                                       (skip-chars-forward " \t\n" (car bounds))
                                       (and (< (point) (car bounds))
                                            (memq (char-after) '(?\( ?\[ ?\{))
                                            (1+ (point))))))
                           (when next (goto-char next))))
                       (throw 'found (point)))))))))
        (goto-char (or target (cdr bounds)))
        (setq my/latex-tab-stop
              (when (and (= (point) (cdr bounds))
                         (or (not argument) (not (texmathp))))
                (cons (point) (buffer-chars-modified-tick))))

(defun my/latex-tab (&optional indent-only)
  "Expand snippets, advance fields/delimiters, or use native indentation.
An ordinary active region and prefix argument always use native indentation."
  (interactive "P")
  (let ((literal (or (nth 4 (syntax-ppss)) (TeX-verbatim-p))))
    (cond
     (indent-only (let ((tab-always-indent t)) (indent-for-tab-command)))
     ((and (use-region-p)
           (not (and (bound-and-true-p yas-minor-mode) (yas-active-snippets))))
      (let ((tab-always-indent t)) (indent-for-tab-command)))
     ((and (not literal) (bound-and-true-p yas-minor-mode) (yas-expand)))
     ((and (bound-and-true-p yas-minor-mode) (yas-active-snippets))
      (yas-next-field))
     (literal (let ((tab-always-indent t)) (indent-for-tab-command)))
     ((equal my/latex-tab-stop (cons (point) (buffer-chars-modified-tick))))
     ((my/latex-math-end)
      (unless (or
               ;; At the start of a math line, indent before navigating.
               (and (<= (point) (save-excursion (back-to-indentation) (point)))
                    (let ((origin (point)) (tick (buffer-chars-modified-tick))
                          (tab-always-indent t))

                      (or (/= origin (point)) (/= tick (buffer-chars-modified-tick)))))

(defun my/notes-ensure-file-visible (filename &optional notes-root)
  "Clear inherited macOS hidden flags for ordinary files under Notes.

visibility, and files outside Notes are left alone."
  (let* ((root (file-name-as-directory
                (expand-file-name (or notes-root "~/Documents/Notes/"))))

    (when (and (eq system-type 'darwin)
               (file-exists-p file)
               (file-in-directory-p file root)

               (string-equal (downcase (or (file-name-extension source) ""))

                                 TeX-command-buffer))

                               (TeX-master-directory))
                           default-directory))

                                       master-dir)))

维护时编辑该 Org 源文件，按 =C-c C-v t= 导出，再执行 =M-x yas-reload-all=。
生成文件中的修改会在下次 tangle 时被覆盖。
片段源文件统一保存在 =latex-mode/=，按文档、数学、环境、引用分组；
AUCTeX 的 =LaTeX-mode= 会继承这套片段。

,* 使用

输入触发词后按 =Tab= 展开；继续按 =Tab= 跳到下一个填写位置。
修改 Org 中的片段后，先 tangle，再执行 =M-x yas-reload-all=。
=inn/=、=norm/=、=set/=、=abs/=、=frac/= 只在数学环境内生效。
其他片段在数学环境外展开。
普通环境和宏也可继续使用 AUCTeX 的 =C-c C-e=、=C-c C-m=。

| 数学 | =abs/= / =frac/= | 绝对值、分式 |

,* 依赖与维护

导言区中的公共宏包来自 =~/Documents/Notes/TeX/cls/=，
现有 Emacs 配置已经设置 TEXINPUTS 和 BIBINPUTS 搜索路径。
=Tools26= 提供 MathMacros26、Fonts26、布局、表格及 TikZ 等公共设置。
=CJKFontsZH26= 管理中文字体及备用字体；使用中文片段时用 XeLaTeX 编译。
英文论文可用 =pre/=；只需最小公共宏包设置时用 =toolsen/= 或 =toolszh/=。
根据已有文档的导言区选择所需片段，避免重复加入整套设置。

数学片段中的 innerp、norm、Set、abs 来自 MathMacros26。
文章中的定理片段依赖 Theorems26；引用片段依赖 biblatex。
=pre/=、=toolsen/=、=toolszh/= 的整套定理设置用于文章。
Beamer 已有自带定理环境，应单独加载 Tools26 和需要的中文字体配置，
避免再加载 Theorems26 造成同名定理冲突。
=bib/= 放在导言区；=printbib/= 放在正文末尾。
图片片段默认使用 TeX Live 自带的 example-image，使用时替换为实际图片名称。
所有旧触发词保留，文件名改为统一的英文小写及连字符形式。
公共字体或宏包设置应在 Notes/TeX 中维护，片段只引用这些配置。

使用现有 TeX 公共资源编译了英文文章、中文文章和 Beamer 示例，
并通过 Biber 及参考文献引用检查。
